# モデル公開の入力

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

`model-source.json` はダウンロード可能なモデル専用アーカイブ、全体のSHA-256、許可した各ファイルのチェックサムとサイズを固定します。`training.json` は、その分類ヘッドの学習に実際に使用した固定の学習・検証行を確認してから出力した公開集計です。分類ヘッドのSHA-256と組み込みラベルの順序に結び付いています。

CI はこの入力からモデル専用 Release を作成します。アプリケーションの配布アーカイブは Actions Artifacts、コンテナイメージは Docker Hub に配置します。現在の取得元は過去のv0.1.0のモデルアーカイブで、全体と各ファイルのチェックサムを検証済みです。

内容で識別する `models-<content-digest>` Release を公開すると、その重みと現在の main のアプリでデプロイ CI を開始します。手動公開は `release.published` で検知し、CI 公開は `tools/publish_models.py --dispatch` から `repository_dispatch` を明示的に送信します。生成するデプロイパッケージはその Release とモデルのダイジェストを固定します。モデル起点のビルドはデプロイ成果物の配布で終了し、モデル公開の再帰を防ぎます。既存バージョンはワークフローの `model_tag` 入力で再ビルドできます。

公開メタデータは人物ごとの学習件数集計と出典を含みます。テスト行は学習件数から除きます。写真、サンプル単位のラベル、生の特徴量、評価データ、APIキーはモデル Release の対象外です。

ダウンロードと更新は [CI/CDガイド](../docs/CI_CD.ja.md)、公開規則全体は[プロジェクト規約](../AGENTS.md)を参照してください。
