# 学習画像数の実験

[English](2026-10-21-sample-size.md) | [简体中文](2026-10-21-sample-size.zh-CN.md) | [日本語](2026-10-21-sample-size.ja.md)

2026-10-21のプロトコルと結果を記録します。

固定の二重バックボーンとロジスティック回帰、確率しきい値0.95のもとで、人物ごとの正しい返却率が95%以上となる学習画像数を推定しました。

ユーザーは実験を依頼し、「人物ごとに正しい識別率95%以上」を選びました。既存の非公開データを用いた探索で、実運用モデル、学習プール、稼働APIは別に管理します。

## プロトコル

- `data/training/features_and_splits.npz` と `samples.jsonl` を使用し、事前学習特徴量を固定します。
- 元のtrain + validationで学習し、testで評価します。sample_id、インデックス、ラベル、元画像SHA、顔画像SHA、ソースグループ分離を確認し、現行ファイルのSHA256を記録します。
- `holdout_protocol.json` 内の二つのハッシュは現行ファイルと異なります。この発見を保持し、配列/行の整合、配備ヘッドと保存スコアの対応、全データ再学習後の予測一致、新しいハッシュ記録で実験の根拠を構成します。
- 学習画像1枚は、各source_groupから選んだ確認済み顔1枚です。連写/写真集の過剰計数を抑えます。既存の重複対策による近似グループであり、撮影の独立性は別途確認が必要です。
- 全実験で50クラスを学習します。対象人物は同時に各N枚を抽出し、他人物の全学習行を固定します。標準化器はその回の選択行で学習します。
- 100枚コホートは学習ソース100以上、テストソース10以上の9人です。
- 50枚コホートは学習ソース50以上、テストソース10以上の12人です。
- 集団が異なるため、コホート別に分析します。
- 枚数は1/2/3/5/8/10/15/20/30/50/75/100で、拡張コホートは50までです。
- 各コホート30回、シード20261021から繰り返します。各反復内のNは同じランダム順序の先頭を使い、グループ代表画像も固定します。抽出記録を保存します。
- テストは人物/ソースごとに代表1枚を独立の固定シードで選び、全N・反復・コホートで共通にします。
- StandardScaler + LogisticRegression(C=1, class_weight=balanced, max_iter=1500, random_state=20261014)を使用し、数値計算を2スレッドに制限します。
- Top-1、正解かつ確率≥0.95の返却率、誤採用率、review、採用結果の適合率を報告します。reviewは未成功で、分母は人物ごとの固定テストソース数です。
- 観測最低枚数は、全30反復と、それより大きい全検証済みNが95%以上となる最小Nです。該当なしはnullで、各人物・各反復も報告します。
- 各実験の片側95% Clopper–Pearson下限の最悪値も示します。反復は同じ独立テストを再利用するため合算しません。下限も95%以上となる厳しい条件も報告します。
- ホールドアウトは以前探索されています。区間は条件付き記述です。未知人物拒否や完全APIの検出・品質失敗は別途評価が必要です。

## 進捗

- 50クラス、5,115件、学習4,064件、テスト1,051件で、主要4フィールドのプール間共通部分は0。
- 全再学習は0.083秒で、配備ヘッドのTop-1を再現し、最大確率差は約2.1e-7。
- 元の1,051顔の基準はTop-1 98.4776%、正しい返却率95.8135%、review 40件。
- 初期660回を完了。全反復達成は50枚群4/12人、100枚群4/9人。
- 結果観察後、100枚群の未達5人が各200以上の学習ソースを持つと判明。固定5人群で125/150/175/200枚を追加し480学習を実施。50クラスとテスト代表画像を保持した後付けの探索です。
- 独立レビューで指標、区間、継続判定、入れ子抽出、テスト代表が再現され、実装不備は見つかりませんでした。元の1,051顔とソース群コホートは集団が異なり、30/30反復達成から将来抽出への95%信頼性は推定できません。
- 追加群の200枚で全反復を達成したのは近藤天音のみで、検証済み継続達成の最低値は175枚。上坂堇、爱美、相羽爱奈、远藤祐里香は200枚でも失敗反復がありました。
- 人物別区間、集計、最悪反復、最低枚数を独立実装とSQLiteの生件数集計で照合。
- データ、配備ヘッド、manifestの前後SHA256は一致。
- 成果物は `data/experiments/sample_size_20261021/report.html`、4コードセルを順に実行した `analysis.ipynb`、CSV、NPZ、抽出記録とソース指紋。
- HTMLパッケージと構造検証は通過。Chromium headless-shellがなく、梱包ツールの規約に従い意味的表のフォールバックを保持。ブラウザー外観と出典ポップオーバーは未検証です。報告はネットワークとローカルAPIに依存せず動作します。
